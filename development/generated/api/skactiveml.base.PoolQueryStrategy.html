PoolQueryStrategy#

class skactiveml.base.PoolQueryStrategy(missing_label=nan, random_state=None)[source]#

Bases: QueryStrategy

Base class for all pool-based active learning query strategies in scikit-activeml.

Parameters:
missing_labelscalar or string or np.nan or None, default=np.nan

Value to represent a missing label.

random_stateint or RandomState instance or None, default=None

Controls the randomness of the estimator.

PoolQueryStrategy.set_params(**params)#

Set the parameters of this estimator.

The method works on simple estimators as well as on nested objects (such as Pipeline). The latter have parameters of the form <component>__<parameter> so that it’s possible to update each component of a nested object.
